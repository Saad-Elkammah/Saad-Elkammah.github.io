Sole developer: I designed, built and operate it
Period

The problem

Arabic language courses need lessons, progress tracking, certificates and paid subscriptions, plus lesson videos that students can stream but can't simply download and share. All of it runs on one server.

What I built

  • Learning: courses, lessons, progress tracking and certificates.
  • Billing: subscriptions with automated invoicing.
  • Protected video: Bunny Stream with signed tokens and HLS.
  • Operations: Laravel, MySQL and Redis on a single server that I run.

Architecture

Built by me External service

Decisions and why

Bunny Stream with signed tokens
Video links are signed, so they can't just be passed around, and HLS streams lessons in segments instead of serving one downloadable file.
Video off the app server
Bunny Stream delivers the video, so the single server only has to run the application.
