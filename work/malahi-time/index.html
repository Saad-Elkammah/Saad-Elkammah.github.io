Mobile ticketing & entertainment · ~32k users

The API behind the Android and iOS ticketing apps, the Vue.js admin dashboards, and the production server they run on.

Role
Full-Stack Developer. I own the API, the admin dashboards, the production server, queues and deployments.
Period
Jan 2026 — Present

The problem

Customers buy tickets in the mobile apps and redeem them by QR code at entertainment branches. Payments have to be reliable, a ticket can only be used once, and notifications have to reach ~32k users.

What I built

  • REST API for the Android and iOS apps: ticket purchase, branches, offers, QR validation and multi-role access.
  • Vue.js admin dashboards.
  • Payments and redemption: payment gateway integrations, including MyFatoorah, and ticket redemption designed against replay attacks, so a ticket can't be used twice.
  • Notifications: rebuilt bulk-notification jobs that took 30–40 seconds each into chunked batches of 200 sent concurrently with Guzzle Pool, and cached the Firebase OAuth token instead of fetching it on every send.
  • Production: I own the Linux server, the queue infrastructure (Redis, Supervisor) and deployments, automated with GitHub Actions.

Architecture

Built by me External service

Decisions and why

Redis with AOF and noeviction
Redis is both cache and queue. AOF persistence and a noeviction policy mean queued payment jobs can never be silently dropped.
Index on users(type, is_active)
Notifications target users by type and active status. The composite index matches that query across ~32k users.
Batches of 200, sent concurrently
Bounded chunks sent in parallel with Guzzle Pool, instead of slow jobs that took 30–40 seconds each.
Cached Firebase OAuth token
The token is expensive to fetch, so it's cached and reused instead of requested on every send.
Supervisor-managed workers
Retries, max lifetimes and graceful shutdown keep workers healthy, and they're restarted correctly during deployments.
GitHub Actions pipeline
Every deploy runs the same steps. SSH keys stay in GitHub Secrets, and a manual trigger is there for controlled releases.
